# Chess bot persona assets

## Provenance

All files in this directory are **original SVG artwork created for this
repository** (BoardGameProject / boardgame-platform). They are **not**
copied from Chess.com, Lichess, Wikimedia piece sets, or any other
third-party chess brand or asset pack.

| File | Description |
|------|-------------|
| `pawn.svg` | Pawn Bot medallion |
| `knight.svg` | Knight Bot medallion |
| `bishop.svg` | Bishop Bot medallion |
| `rook.svg` | Rook Bot medallion |
| `queen.svg` | Queen Bot medallion |
| `king.svg` | King Bot medallion |
| `bot-badge.svg` | Optional BOT pill glyph |

**Style:** circular medallion, brass ring, dark wood fill, subtle robotic
accent, classical piece silhouette — same visual family, slight brass/wood
tint shifts by difficulty tier.
